# AutoNektome 🚀

![Версия](https://img.shields.io/badge/версия-6.1-brightgreen) ![Лицензия](https://img.shields.io/badge/лицензия-MIT-blue)

**AutoNektome** — это продвинутый пользовательский скрипт для [nekto.me/audiochat](https://nekto.me/audiochat), добавляющий автоматизацию, управление голосом, изменение голоса и улучшенный интерфейс.

## ✨ Возможности

- **🔄 Авторежим:** Автоматический поиск собеседника и пропуск диалогов.
- **🎙️ Голосовое управление:** Управляйте чатом командами ("Скип", "Стоп", "Старт") даже когда браузер свернут.
- **🔊 Аудио настройки:**
  - **Изменение голоса:** Настройка тональности (Pitch Shift) в реальном времени.
  - **Студийный звук:** Компрессия и эквализация для улучшения звучания микрофона.
  - **Шумоподавление:** Активное подавление фонового шума.
  - **Самопрослушивание:** Возможность слышать себя для настройки микрофона.
- **🎨 Оформление:** Встроенная темная тема "GitHub Dark".
- **📊 Статистика:** Счетчик количества разговоров.

## 🛠 Установка

1. Установите расширение **Tampermonkey** для вашего браузера (Chrome, Firefox, Edge, Яндекс.Браузер).
2. Установите скрипт: [Установить AutoNektome](https://raw.githubusercontent.com/pawyc/AutoNektomeV2/main/AutoNektome.user.js).
3. Откройте [nekto.me/audiochat](https://nekto.me/audiochat). Меню управления появится автоматически в правом верхнем углу.

> **Автообновление:** если скрипт установлен по GitHub-ссылке выше, Tampermonkey будет получать обновления автоматически после публикации новой версии в `main`.

> **Важно:** Для работы всех аудио-функций (изменение голоса, автогромкость) необходимо разрешить доступ к микрофону на сайте.

## ⚙️ Управление

- **Меню:** Кликните по заголовку "AutoNektome" в углу экрана, чтобы свернуть/развернуть настройки.
- **Голосовые команды (по умолчанию):**
  - *Скип / Skip / Далее* — следующий собеседник.
  - *Стоп / Завершить* — остановить поиск.
  - *Старт / Чат / Поиск* — начать поиск.
